# Инжиниринг управления данными

Учебный проект по дисциплине «Инжиниринг управления данными». Репозиторий предназначен для размещения домашних заданий и итогового проекта по работе с датасетом из открытых источников.

Итоговый проект будет основан на данных, полученных путём парсинга сайта интернет-магазина «Золотое Яблоко». 
Цель — отработать подготовку, организацию и анализ данных на примере товарного каталога.

## Содержание репозитория

- **Домашние задания** — решения и материалы по темам дисциплины.
- **Итоговый проект** — обработка датасета, исследование данных и представление результатов.

Материалы будут добавляться по мере выполнения учебных работ.

## Датасет

Источник данных — сайт [«Золотое Яблоко»](https://goldapple.ru/). Исходный файл — `gold_apple.csv` хранится на [Google-диске](https://drive.google.com/file/d/1Bj9C5NBc6cEi3SFhE-WCLmxxfzxfIxsi/view?usp=sharing).


Датасет содержит **1 149 записей и 15 столбцов**. Каждая строка описывает товар или его вариант, например отдельный оттенок. В выборке представлены товары для макияжа, ухода и другие категории каталог

## Источник и получение данных

В проекте используется готовый датасет, полученный с сервиса [XMLDataFeed](https://xmldatafeed.com/catalog/scraping/beauty/goldapple/). Данные собраны сервисом путём парсинга сайта интернет-магазина «Золотое Яблоко».

Самостоятельный парсинг в рамках проекта не выполнялся. Датасет будет использоваться для учебных задач по очистке, обработке и анализу данных.


| Столбцы | Содержание |
| --- | --- |
| `Код товара`, `Артикул` | Идентификаторы товаров |
| `Категория`, `Тип продукта` | Раздел каталога и вид продукта |
| `Бренд`, `Название` | Бренд и название товара |
| `Характеристика`, `Объем` | Характеристика варианта, например оттенок, и объём |
| `Описание`, `Инструкция по применению` | Текстовая информация о продукте и его использовании |
| `Цена`, `Старая цена` | Цена и прежняя цена, указанные в выгрузке |
| `Ссылки на картинки`, `Ссылка на товар` | Адреса изображений и страницы товара |
| `Дата обновления` | Дата обновления записи |

Формат файла — CSV, разделитель — точка с запятой (`;`), кодировка — UTF-8.
